# Synthetic demo inputs

Generated by `python tools/generate_demo.py`. These files describe an artificial room and trajectory, not a measured run. Coordinates are metres and timestamps are seconds. Safe to redistribute under the project MIT license.

The RTAB-Map database is a minimal compatible schema fixture, not a database produced by RTAB-Map. Use it to try the UI. Native RTAB-Map 0.23.13 RGB-D databases are tested separately and are not published.
