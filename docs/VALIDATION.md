# Validation

This page separates data-analysis checks from desktop/platform evidence. Public screenshots and demo recordings use synthetic inputs only. Native robot databases used locally are not redistributed.

## Regression suite

`python -m unittest discover -s tests -v`: **28 tests**, covering Windows/Python 3.11 and Ubuntu 24.04/Python 3.12 locally, plus the CI matrix below.

Coverage includes bounded RVL/matrix decoding, malformed depth/calibration, SQLite WAL snapshots, cancellation, empty/pose-only databases, TUM timestamp/quaternion checks, KITTI rotation validation, explicit CSV orientation, g2o references/SE3 poses, PCD packed RGB, unsupported compression, PLY invalid points and end-to-end source-preserving reports.

For a report folder, `python tools/verify_output.py FOLDER` verifies input hashes, all listed PNG/SVG files, PDF page counts, local HTML links and ZIP CRC. The report ZIP excludes the independent input snapshot.

## Platform builds

The [Actions workflow](https://github.com/nguyenbinh-shark/rpbot-map-studio/actions/workflows/ci.yml) provides current build/test evidence for Windows Server 2022 and Ubuntu 22.04. Each matrix job runs regression tests, builds a standalone binary, launches its GUI on synthetic RGB-D input, checks visible-window/completion evidence and validates the generated report. It also executes the standalone CLI on a TUM input.

Local Linux desktop checks use Ubuntu 24.04 under WSL2/Xvfb. This validates the Linux runtime and mapped Tk window in an isolated X server; it is not manual testing on every native Linux desktop or graphics stack. The local Windows standalone test also ran with external Python/GCC/WSL removed from `PATH`.

## Limits

Tests do not establish SLAM accuracy, calibrated sensor quality, navigation suitability, new loop closures or general compatibility with all RTAB-Map versions. No ATE/RPE or hardware navigation trial is claimed. The synthetic RTAB-Map fixture is a minimal compatible schema generated by this repository, not an upstream-produced database.
